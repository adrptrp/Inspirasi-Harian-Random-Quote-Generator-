# Inspirasi Harian - Random Quote Generator 💡

Repositori ini berisi *source code* untuk pemenuhan tugas **Final Project Web Development 2.0** dari Google Developer Groups on Campus (GDGoC) UIN Syarif Hidayatullah Jakarta. 

Aplikasi ini adalah *Single Page Application* (SPA) sederhana yang dirancang untuk menampilkan kutipan acak kepada pengguna, menggunakan integrasi data dinamis dari API publik.

## ✨ Fitur Utama

* **Dynamic Data Fetching:** Menggunakan JavaScript Asynchronous (`Fetch API`) untuk mengambil data dari server eksternal secara *real-time* tanpa perlu memuat ulang halaman.
* **Responsive Layout:** Dibangun menggunakan kombinasi tata letak modern **CSS Grid** dan **Flexbox**, memastikan website dapat beradaptasi dengan sempurna di perangkat *desktop*, tablet, maupun *mobile*.
* **Interactive UI:** Dilengkapi dengan *feedback* visual seperti indikator *loading* dan *state management* pada tombol saat pengambilan data sedang berlangsung untuk mencegah *spam click*.

## 🎨 Pendekatan UI/UX

Desain antarmuka aplikasi ini tidak sekadar fungsional, tetapi juga dibangun dengan mempertimbangkan analisis prinsip dasar antarmuka pengguna (UI) dan pengalaman pengguna (UX):
* **Hierarki Visual:** Pemisahan yang jelas antara *Landing Page* dan *Main Feature* menggunakan pewarnaan (*whitespace* dan warna *background*) untuk memandu mata pengguna.
* **Usability:** Navigasi dibuat ringkas dan tombol *Call-to-Action* (CTA) diposisikan secara strategis untuk interaksi yang intuitif.

## 🛠️ Tech Stack

Proyek ini dikembangkan secara *Native/Vanilla* tanpa menggunakan *library* atau *framework* eksternal tambahan:
* **HTML5** (Semantic Structure)
* **CSS3** (Styling, Flexbox, & Grid)
* **JavaScript** (DOM Manipulation & ES6+ Async/Await)
